# Expense Tracker

Приложение для учёта личных расходов: добавление и редактирование операций, фильтрация по периоду и визуальная аналитика.

**[Открыть демо](https://user49324809.github.io/tracker/)**

## Возможности

- добавление, редактирование и удаление расходов;
- фильтры за текущий месяц, год или выбранный диапазон;
- расчёт общей суммы и разбивка по категориям;
- круговая диаграмма категорий и график за последние 12 месяцев;
- сохранение данных в `localStorage` без отправки на сервер;
- адаптивная верстка для компьютеров и мобильных устройств.

## Технологии

- React 19;
- JavaScript;
- Chart.js и react-chartjs-2;
- CSS;
- Jest и React Testing Library;
- GitHub Pages.

## Локальный запуск

```bash
git clone https://github.com/user49324809/tracker.git
cd tracker
npm install
npm start
```

## Проверка

```bash
npm test -- --watchAll=false
npm run build
```

## Хранение данных

Все операции сохраняются только в браузере пользователя. Очистка данных сайта в браузере удалит историю расходов.
